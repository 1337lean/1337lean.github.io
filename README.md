# lean

Personal GitHub Pages portfolio for lean.

A clean, high-craft developer portfolio showcasing web products, native iOS applications, and open-source infrastructure tools. Features a modern minimalist design system, clean typography, categorized project layout, and an accessible light/dark theme.

## Projects

### Featured Products
- [Portal](https://portalchat.org) — frontend for a passkey-first encrypted messaging platform with chats, media, and calls
- [buffer.lol](https://buffer.lol) — browser-based network diagnostics, IP lookups, and developer tools
- [7331.cloud](https://7331.cloud) — anonymous temporary image hosting with a companion [Go CLI](https://github.com/1337lean/7331-cli)
- [Neon Tether](https://neontether.com) — a one-thumb orbital score-chaser for iPhone ([source](https://github.com/1337lean/neon-tether))
- [IP Lens](https://buffer.lol/ip-lens) — a privacy-focused native iPhone toolkit for IP intelligence

### Developer Tools & Systems
- [Envguard](https://github.com/1337lean/envguard) — dependency-free dotenv contract validation without secret exposure
- [Certpulse](https://github.com/1337lean/certpulse) — batch TLS certificate, protocol, and OCSP health checks
- [Relaybox](https://github.com/1337lean/relaybox) — durable webhook capture, verification, retry forwarding, and live inspection
- [Gatehouse](https://github.com/1337lean/gatehouse) — release-bundle policy checks for CI and deployment boundaries
- [Kevin](https://github.com/1337lean/kevin) — modular Discord bot with a Telegram AI companion

## Local Development

Open `index.html` directly in any browser, or start a static server:

```bash
python3 -m http.server 8000
```

Then navigate to <http://localhost:8000>.
